# KKKO18 Shuffle Example Source Review

## Scope

This was a report-only review for `Shuffle Lemmas for Quiver-Hecke Modules`.

No paper was downloaded. No claim, topic page, source note, Sage code, image, or example was added.

## Question

Can the already ingested `kkko14-monoidal-categorification-cluster-algebras` source support a compact source-specific worked example for the shuffle lemma cited in KN25 as KKKO18 Proposition 10.1.5?

## Finding

No. The local PDF is the 2014 arXiv v1 preprint and does not contain Section 10, Proposition 10.1.5, or a worked shuffle-lemma example.

Therefore no visible example should be added to `Shuffle Lemmas for Quiver-Hecke Modules` from this local source.

## Source Locations Checked

- Local PDF: `content/assets/pdfs/kkko14-monoidal-categorification-cluster-algebras.pdf`.
- `pdfinfo` reports 44 pages.
- Extracted text line 8 identifies the local file as `arXiv:1412.8106v1 [math.RT] 28 Dec 2014`.
- Extracted text around lines 228-236 says the paper is organized through Sections 1-6 and that Section 6 proves the main theorem.
- Extracted text around lines 1694-1708 begins Section 6, `Monoidal categorification via modules over KLR algebras`.
- Extracted text around lines 2120-2140 is already in Corollary 6.4 and the references area.
- Searches for `Proposition 10.1.5`, `10.1.5`, and `shuffle` in the extracted local PDF text found no relevant match.

KN25 does cite the final published source:

- `inbox/papers/crystal.tex`, lines 2655, 2668, 2680, and 2712 cite `\cite[Proposition 10.1.5]{KKKO18}` for the shuffle-filtration statements.
- `inbox/papers/crystal.tex`, lines 4921-4924 identify `KKKO18` as `Monoidal categorification of cluster algebras`, J. Amer. Math. Soc. 31 no. 2 (2018), 349-426.

The current local source note and PDF therefore should not be treated as containing the final JAMS Proposition 10.1.5.

## Proposed Example Wording

None.

The current evidence supports leaving the example section absent. A visible example would require an approved, legally accessible source that actually contains Proposition 10.1.5 or a compact worked shuffle case.

## Recommended Next Step

Ask for explicit approval to evaluate legal access to the final JAMS 2018 version, or to a later legitimate open-access version if one exists, only for Proposition 10.1.5 and any worked shuffle-lemma example. Keep that next pass report-only before editing the topic page.
