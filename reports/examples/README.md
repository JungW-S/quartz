# Example Verification Reports

Use this directory for optional short verification reports for topic-page examples.

Recommended filename:

```text
reports/examples/YYYY-MM-DD-<example-id>.md
```

A report should record:

- topic id and example id,
- verification type: `논문 예시`, `Sage 계산`, or `논문 그림`,
- exact source location or Sage command,
- generated image path if applicable,
- intentionally omitted details or human-review cautions.
