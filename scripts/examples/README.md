# Sage Example Scripts

Store checked Sage scripts for topic-page examples here.

Use one directory per topic id:

```text
scripts/examples/<topic-id>/<example-id>.sage
```

Each script should first construct and verify the mathematical object or computation. If the example needs a visual asset, generate the image only after the mathematical checks pass.

Topic pages may use a Sage-based example only when its script is stored here and the example has the visible label `검증: Sage 계산`.
