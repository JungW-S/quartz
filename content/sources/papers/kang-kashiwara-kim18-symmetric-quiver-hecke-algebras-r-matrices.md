## Intake Scope

This source note records only the construction-level material imported for `Quantum Affine Schur-Weyl Duality`, the compact type \(A\) denominator example imported for `Quantum Affine R-Matrix Denominators`, the Section 4.2-4.3 segment-module prerequisite imported for `Type A KLR Segment Modules`, and the Proposition 4.2.3/Lemma 4.2.6 convolution mechanism imported for `Type A Segment Module Convolutions`. It is not a paper summary.

## Imported Claim Index

- `kkk18a-rmatrix-denominator-klr-parameters`: normalized R-matrix denominator data determine the KLR parameters and quiver used in the functor construction; source location: Section 3.1, arXiv PDF pp.26-27, lines 2088-2134.
- `kkk18a-completed-tensor-bimodule-construction`: the completed tensor object built from affinizations of the chosen quantum-affine modules carries a \((U_q'(\mathfrak g),R^J(\beta))\)-bimodule structure; source location: Section 3.1 and Theorem 3.1.3, arXiv PDF pp.29-30, lines 2197-2365.
- `kkk18a-schur-weyl-tensor-functor-exactness`: the functors \(F_\beta\) assemble into a tensor functor, and \(F_\beta\) is exact when the associated quiver is finite type ADE; source location: Section 3.2 and Theorem 3.3.3, arXiv PDF pp.30-33, lines 2366-2424 and 2587-2600.
- `kkk18a-type-a-segment-module-definition`: type \(A\) segments, multisegments, and the one-dimensional graded module \(L(a,b)\); source location: Section 4.2, arXiv PDF p.36.
- `kkk18a-ordered-multisegment-classification`: finite-dimensional simple graded \(R(\ell)\)-modules are classified by ordered multisegments through heads of convolution products of segment modules; source location: Proposition 4.2.5, arXiv PDF p.39.
- `kkk18a-segment-module-schur-weyl-image`: \(F(L(a,b))\simeq V(\varpi_\ell)_{(-q)^{a+b}}\) for \(0\le\ell\le N\) and \(F(L(a,b))=0\) for \(\ell>N\); source location: Proposition 4.3.1, arXiv PDF pp.43-44.
- `kkk18a-two-segment-rmatrix-case-analysis`: zero orders and renormalized R-matrix homomorphisms for two segment modules by interval-position cases; source location: Proposition 4.2.3, arXiv PDF pp.37-39.
- `kkk18a-segment-convolution-irreducibility-cases`: nested and separated interval cases give irreducible convolution products; source location: Proposition 4.2.3 (iii)-(iv), arXiv PDF p.37.
- `kkk18a-segment-convolution-exact-sequence-cases`: crossing and adjacent interval cases give exact sequences whose R-matrix images identify head and socle; source location: Proposition 4.2.3 (v)-(vi), arXiv PDF p.37.
- `kkk18a-ordered-segment-convolution-head-socle`: ordered segment convolutions have heads matching shifted socles of reversed convolutions; source location: Lemma 4.2.6, arXiv PDF pp.39-41.
