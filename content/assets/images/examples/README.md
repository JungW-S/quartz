Store generated or source-derived topic-page example images here.

Use one directory per topic id:

```text
content/assets/images/examples/<topic-id>/<example-id>.<png|svg>
```

Images in this directory must come from either:

- checked Sage code stored under `scripts/examples/<topic-id>/`, or
- an approved paper/book/lecture figure, table, or page recorded in `Source notes`.

Do not store LLM-generated mathematical figures here unless the mathematical content has been independently verified by an approved source or checked Sage code.
